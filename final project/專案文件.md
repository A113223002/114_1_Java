# 線上訂餐系統（Online Food Ordering System）專案文件

## 一、專案名稱

線上訂餐系統（Online Food Ordering System）

## 二、專案目的

本專案旨在模擬常見外送平台（如 Uber Eats、foodpanda）的核心訂餐流程，透過 Java 物件導向程式設計，實作餐點管理、套餐與單點選擇、客製化需求、外送費與尖峰費計算，以及訂單存檔等功能，藉此熟悉類別設計、繼承、介面（interface）與集合（ArrayList）的應用。

## 三、系統功能說明

1. 顧客可輸入姓名與餐廳名稱建立訂單。
2. 提供「套餐」與「單點」兩種訂餐方式：

   * 套餐享有 85 折優惠。
   * 單點可選擇主餐、附餐或飲料。
3. 飲料提供冰塊客製化（去冰、少冰、正常冰）。
4. 主餐與附餐可進行文字型客製化說明。
5. 支援多份餐點與相同套餐數量合併。
6. 依外送距離計算外送費（每公里 10 元）。
7. 尖峰時段加收尖峰費 15 元。
8. 顯示完整訂單明細與總金額。
9. 將訂單紀錄輸出並附加存檔至文字檔（order.txt）。

## 四、系統架構說明

本系統主要分為三個部分：

* **介面層（interfaces）**：定義系統中可擴充的行為規範。
* **資料模型層（model）**：負責餐點、訂單、顧客等核心資料與商業邏輯。
* **主程式（Main）**：負責使用者互動流程與系統整體執行。

## 五、介面（Interface）設計說明

### 1. Customizable

* 功能：定義餐點可客製化的行為。
* 方法：

  * applyCustomization(String option)
  * getCustomizations()
  * getCustomizationFee()

### 2. DeliveryFeeCalculator

* 功能：定義外送費計算規則。
* 方法：

  * calculateDeliveryFee(int distance)

### 3. Discountable

* 功能：定義折扣行為。
* 方法：

  * applyDiscount(double total)

### 4. Preparable

* 功能：定義餐點準備時間。
* 方法：

  * getPrepareTime()

（以上介面為系統預留擴充設計，目前部分功能已直接於類別中實作。）

## 六、類別設計說明（Model）

### 1. MenuItem（抽象類別）

* 屬性：name、price
* 方法：getName()、getPrice()、getType()
* 說明：作為所有餐點的共同父類別。

### 2. MainDish / SideDish / Beverage

* 繼承 MenuItem。
* Beverage 額外包含 iceLevel（冰塊選項）。

### 3. ComboMeal

* 功能：同時代表「套餐」與「單點」的餐點組合。
* 內容包含主餐、附餐、飲料、數量、客製化內容與套餐標記。
* 提供原價與折扣後價格計算。

### 4. Order

* 功能：管理單筆訂單。
* 內容包含顧客名稱、餐廳名稱、餐點清單、外送費、尖峰費。
* 提供總金額計算與檔案輸出格式。

### 5. Customer

* 功能：儲存顧客名稱與歷史訂單紀錄。

### 6. Restaurant

* 功能：管理餐廳名稱與菜單清單，並提供顯示與輸入菜單功能。

## 七、主程式（Main）流程說明

1. 輸入顧客姓名與餐廳名稱。
2. 選擇套餐或單點流程。
3. 輸入餐點資訊、客製化選項與數量。
4. 輸入外送距離並計算外送費。
5. 選擇外送時段並判斷是否為尖峰。
6. 顯示完整訂單明細。
7. 將訂單內容寫入 order.txt 檔案中保存。

## 八、使用技術與重點

* Java 類別與物件導向設計
* 繼承與抽象類別
* 介面（Interface）設計
* ArrayList 集合操作
* 例外處理（IOException）
* 檔案輸出（FileWriter）
* Scanner 使用者輸入

## 九、執行方式

1. 將專案匯入 Java 開發環境（如 IntelliJ IDEA / Eclipse）。
2. 確保所有套件結構正確。
3. 執行 Main 類別。
4. 依照畫面指示輸入訂餐資訊。

## 十、結論與心得

本專案透過模擬實際訂餐情境，加深對 Java 物件導向設計的理解，特別是在類別分工、繼承關係與功能封裝方面。系統亦保留介面設計，方便未來擴充更多功能，如不同折扣策略或外送費計算方式，具有良好的延展性。
